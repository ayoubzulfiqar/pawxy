# Contributing to Pawxy VPN

Thank you for your interest in contributing to **Pawxy VPN**! We welcome contributions from the community to help make Pawxy faster, safer, and easier to use across all platforms.

---

## How to Contribute

### 1. Reporting Bugs
Before submitting a new issue, please check existing GitHub issues to avoid duplicates. When filing a bug report, please use our Bug Report issue template and include:
* Operating system and device model.
* Steps to reproduce the bug.
* Expected vs actual behavior.

### 2. Suggesting Features
Enhancements and new feature requests are welcome! Use our Feature Request template to describe the problem or use-case you'd like Pawxy VPN to solve.

### 3. Submitting Code Changes
1. Fork the repository on GitHub.
2. Create a topic branch (`git checkout -b feature/amazing-feature`).
3. Make your changes adhering to Flutter/Dart style guidelines (`flutter format` and `flutter analyze`).
4. Ensure all tests pass (`flutter test`).
5. Commit your changes with clear, descriptive commit messages.
6. Push to your branch and open a Pull Request targeting `main`.

---

## Code Style & Guidelines
* Follow official Dart and Flutter lints.
* Ensure code is null-safe and properly typed.
* Write unit/widget tests for new features where applicable.
