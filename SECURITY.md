# Security Policy

## Supported Versions

We actively issue security updates and patches for the following versions of **Pawxy VPN**:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

---

## Reporting a Vulnerability

Security is a core priority for Pawxy VPN. If you discover a potential security vulnerability, please do **NOT** open a public issue on GitHub.

Instead, please report security concerns directly to the creator **Ayoub Zulfiqar**:
* Website Contact: [https://ayoubzulfiqar.com](https://ayoubzulfiqar.com)
* Project Details: [https://ayoubzulfiqar.com/projects/pawxy](https://ayoubzulfiqar.com/projects/pawxy)

### Response Timeline
* **Initial Acknowledgment**: Within 48 hours.
* **Status Update**: Within 5 business days after investigation.
* **Fix & Release**: Security patches will be issued promptly upon resolution.

Thank you for helping keep Pawxy VPN secure for everyone!
